PROJET : NEXIAL

1. POSITIONNEMENT
Nexial est un copilote d’investissement boursier moyen / long terme.
Ce n’est PAS un outil de trading court terme.

Objectif :
→ Aider l’utilisateur à prendre de meilleures décisions
→ Réduire le nombre de décisions
→ Maximiser la performance avec discipline

Cible :
→ Débutant (guidé)
→ Intermédiaire (structuré)
→ Expert (optimisé via mode expert)

2. PARCOURS UTILISATEUR
Phase 1 : Je visualise
→ comprendre rapidement (dashboard)

Phase 2 : Je structure et j’agis
→ invest now + entry plan

Phase 3 : Je pilote la performance
→ arbitrage + optimisation

Règle :
→ peu d’actions (max 3)
→ toujours actionnable
→ toujours explicable

3. MONÉTISATION
FREE :
→ comprendre
→ dashboard + actions limitées + broker advisor

STARTER (~5€) :
→ tester
→ quelques plans limités

CORE (~20€) :
→ agir
→ invest now complet + arbitrage + entry plan + mode expert

PRO :
→ plus tard

Objectif :
→ rentabilité rapide (≈ 5 utilisateurs payants)
