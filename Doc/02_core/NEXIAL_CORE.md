# NEXIAL CORE

## Architecture

Signal → Premarket → Alerts → Entry Plans → Actions

---

## Philosophy

- Capital efficiency first
- No forced trades
- Buy on pullback only
- Max 3 ideas
- WAIT is a valid decision

---

## Market Timing

Europe:
- 09:00 premarket
- 09:30 open
- 17:30 close

US:
- 15:00 premarket (14:00 winter)
- 15:30 open (14:30 winter)
- 21:00 close

Special:
- Friday late session = pullback opportunity

---

## Opportunity Thresholds

-2% → WATCH  
-3% → WATCH_STRONG  
-5% → ENTRY_PLAN  
-8% → BUY_ZONE  

---

## Execution Rules

- ENTRY_PLAN → prepare order
- BUY_ZONE → validate in Actions
- WATCH → monitor only

---
