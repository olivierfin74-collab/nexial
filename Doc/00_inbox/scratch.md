# NEXIAL — SCRATCH

## Rôle du fichier

Fichier temporaire de travail pendant une session.

Ce fichier sert uniquement à capturer rapidement :
- idées
- tests
- notes brutes
- bugs observés
- décisions en réflexion
- extraits SQL / UI à retraiter

---

## Règle principale

`scratch.md` est un brouillon.

Rien dans ce fichier n’est considéré comme officiel tant que ce n’est pas transféré dans :

- `01_state/CURRENT_STATE.md`
- `01_state/NEXIAL_STATE.md`
- `01_state/NEXT_ACTION.md`
- `02_core/`
- `03_changelog/CHANGELOG.md`

---

## Utilisation recommandée

Pendant une session :

1. noter rapidement les points importants
2. capturer les bugs / décisions
3. stocker les idées non encore validées
4. transférer uniquement ce qui compte en fin de session
5. vider ou archiver si nécessaire
