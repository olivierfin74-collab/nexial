# ONBOARDING — NEXIAL

## Objective
User understands and acts in < 2 minutes

## Flow

1. Welcome screen
2. Portfolio creation (manual or test)
3. Analysis
4. Decision display

## Rules

- No explanation needed
- No complex UI
- Immediate clarity

## Test

User must:
- understand in < 30 sec
- take an action without guidance

If not → UX issue
